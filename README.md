# Study Planner 📚

برنامج بسيط بلغة Python لتنظيم المهام الدراسية ومتابعة إنجازها.
يعمل البرنامج داخل Google Colab من خلال قائمة تفاعلية.

## المميزات ✨

- إضافة مهمة مع اسم المقرر والمدة المتوقعة وموعد الاستحقاق.
- عرض جميع المهام وحالة كل مهمة.
- تحديد المهام المكتملة.
- عرض ملخص يشمل عدد المهام ونسبة الإنجاز والوقت المتبقي.
- اقتراح مهمة غير مكتملة وحساب عدد جلسات الدراسة اللازمة لها.

## طريقة الاستخدام 🚀

1. افتح المشروع في Google Colab من الرابط أدناه.
2. اختر **Runtime → Run all** لتشغيل جميع الخلايا.
3. عند ظهور القائمة التفاعلية، أدخل رقم العملية المطلوبة واتبع التعليمات.
4. لإنهاء البرنامج، اختر **6. Exit**.

[فتح Study Planner في Google Colab](https://colab.research.google.com/github/Alomiry/learn-git-with-pathy/blob/main/py_project.ipynb)

## التقنيات المستخدمة 🛠️

- Python
- Google Colab
